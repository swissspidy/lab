How to read this

The lab improves a website one experiment at a time. For each experiment an agent writes a hypothesis, the change it wants to make and acceptance criteria. The change is built as a patch and tested in a sandbox. It must pass every check: the site's own invariants (what the site must always do), quality budgets (accessibility, errors, speed, layout) and its own criteria. Only then can a person approve it. It is then shown to a share of visitors, measured against the current site on one metric, and kept or reverted. Rejected and reverted experiments are normal results.

P(expected effect) is the probability, given the data so far, that the change moves the metric the way the hypothesis says. The lab keeps a change at 0.95 or more and reverts it at 0.05 or less.
